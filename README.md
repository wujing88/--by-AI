## 1. 🖥️ 电脑端 50/50 分屏双轨协同训练法

为了获得最极致的脱敏控精与耐力突破效果，强烈推荐在 **PC 桌面端 / 宽屏显示器** 采用 **「视觉刺激 + 节奏控速」双轨分屏** 方式。

### 📐 屏幕布局示意图
```
+------------------------------------+------------------------------------+
|                                    |                                    |
|          左半屏 (50%)              |            右半屏 (50%)            |
|                                    |                                    |
|       🎥 视觉刺激源 (视频播放器)     |       🔥 律动节拍器 (本应用)        |
|                                    |                                    |
|   · 接受高强度心理/视觉刺激         |   · 严格掌控器具抽插/握持节奏      |
|   · 考验中枢神经兴奋度耐受         |   · 视觉光晕 + 精准音频倒计时      |
|                                    |                                    |
+------------------------------------+------------------------------------+
```

### ⚡ 极速分屏配置步骤
1. **贴边分屏**：
   * **Windows**：选中视频窗口按 `Win + ←`，选中本应用浏览器窗口按 `Win + →`。
   * **macOS**：长按窗口左上角绿色全屏按钮，选择「将窗口拼贴到屏幕左侧/右侧」。
2. **声音配比建议**：
   * 佩戴耳机，将本应用节拍音量调至 **60%~70%**，背景视频音量调至 **30%~40%**，确保节拍清晰可辨。
3. **器具与润滑准备**：
   * 推荐配合慢玩型/进阶锻炼型飞机杯或紧致训练胶体，涂抹充足水溶性润滑液，保持舒适湿润。

```
     (2分钟)               (2分钟)               (2分钟)               (2分钟)             (1分钟)
```

| 阶段 | 节奏 (BPM) | 拍频速度 | 器具动作与配合口诀 | 神经脱敏目标 |

## 4. 🌙 夜间私密模式与系统深浅色自动跟随

* **🖥️ 跟随系统设置（默认开启）**：

  * 系统切换到深色时，自动开启**「暗夜玫瑰」**；系统切换到浅色时，自动恢复清新马卡龙配色。

## 8. 💡 进阶脱敏重塑与身心防护法则

1. **绝对死守急刹车原则**：
   * 训练的目的是**「延迟阈值」**而非宣泄。若在 90 或 120 BPM 感觉即将失控，可提前将视线移开视频，深吸气并默数拍子；
   * **在降温阶段绝不可继续抽动**，让神经系统建立“极度兴奋 ➔ 自主冷静”的正确反馈通路。
2. **多轮训练的“神奇第二轮”**：
   * 推荐每次进行 **2~3 轮（20~30 分钟）**；
   * 当第 1 轮结束后重新进入第 2 轮的 30 BPM 时，你会发现敏感度大幅下降，耐受力成倍跃升。
3. **循序渐进与规律作息**：
   * 建议每周进行 **3~4 次** 规律训练，避免单日过度疲劳；
   * 保持良好睡眠与充足水分补充，健康锻炼，稳步突破！

## 9. 🚀 Cloudflare (Pages / Workers) 极速部署指南

项目已原生兼容 **Cloudflare Pages** 与 **Cloudflare Workers (with Assets & Durable Objects)**：

### 方案 A：Cloudflare Pages（推荐，连接 GitHub 自动构建部署）
1. 将代码推送到您的 **GitHub 仓库**；
2. 登录 **Cloudflare Dashboard** ➔ 点击 **Workers & Pages** ➔ **Create application** ➔ **Pages** ➔ **Connect to Git**；
3. 选择刚刚推送的 GitHub 仓库，填写构建配置：
   * **Framework Preset**：`Vite`
   * **Build command**：`npm run build` 或 `vite build`
   * **Build output directory**：`dist`
4. 点击 **Save and Deploy** 即可完成全球多节点 CDN 部署（已内置安全响应头 `_headers`）。

### 方案 B：Cloudflare Workers (Wrangler CLI)
* 构建并直接部署 Workers 全栈版（含实时在线律动同伴 WebSocket 服务）：
  ```bash
  npm run build
  npx wrangler deploy
  ```
  > `wrangler.jsonc` 已配置 `"not_found_handling": "single-page-application"` 自动托管 SPA 路由。
